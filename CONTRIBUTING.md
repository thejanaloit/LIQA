# Contributing to LIQA

1. Headed Worker is the product. Do not add a headless SKU as the default path.
2. Never commit `.env`, vault JSON, captures, or API keys.
3. Hands must move visibly (Bezier) then click. Never teleport.
4. If a control is not on the latest screenshot, stop and ask — never guess x/y.
5. Hard CAPTCHA / SMS / Google 2FA = human gate. No captcha farms, no OTP invention.
6. Cursor API is a job dispatcher only. UAT pixels stay on the Worker in bank mode.
7. Pull requests: describe the headed proof you ran locally (`scripts/smoke.ps1` + `/health`).
8. New features land behind a todo id in `docs/TODO.md` or `docs/TODO-HUMAN.md`.
