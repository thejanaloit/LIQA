# ADR-0003 — Model-agnostic brain

Status: accepted  
Date: 2026-09-10

Brain is a function: screenshot + context → next action JSON.

Bank SKU: local Ollama/vLLM on or beside the Worker.

Cloud brain: opt-in, non-regulated only.

The product is the Worker + loop, not a single model vendor.
