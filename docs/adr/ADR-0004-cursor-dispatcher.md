# ADR-0004 — Cursor API is dispatcher only

Status: accepted  
Date: 2026-09-10

`https://api.cursor.com` may start an agent run. Clicks still happen on **LIQA Worker** (Windows headed).

Cursor computer-use is macOS/Linux. It is not the FusionX/UAT mouse.

Never put UAT passwords or full-desktop bank screenshots into Cursor Cloud by default.
