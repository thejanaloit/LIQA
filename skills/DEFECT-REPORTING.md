# Defect reporting skill

1. Crop proof PNG to the exact defect point.
2. Red highlight on the Issue cell / image region.
3. Plain English: expected vs actual; who is hurt; which story/tenant.
4. Honesty: REAL_BUG only after contract; else PASS / BLOCKED / N/A.
5. Draft with `mqa_file_bug_draft` then create Jira issue via Atlassian MCP + attach PNG.
6. Tone: match harvested PF-59194 / TestCrafters style — not generic AI fluff.
